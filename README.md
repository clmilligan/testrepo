# Gradebook Project
### Clemi Milligan
The Gradebook is a Python program designed to help users manage and analyze their academic grades across multiple subjects. Users can add and remove grades, view individual grades and class averages, calculate their cumulative GPA on a 4.0 scale, and identify their strongest and weakest subjects.
## Contains:
gradebook.py --> runs the code includes methods needed and main
grades.csv --> contains the values of the grades in each class
README.md --> gives information about the code
